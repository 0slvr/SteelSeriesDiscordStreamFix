# Contributing

Thanks for your interest in improving this project!

## Reporting bugs
Use the **Bug report** template and attach your log file.

## Suggesting features
Open an issue describing the problem you want solved, not just the solution.

## Pull requests
1. Fork the repo and create a branch from `master`.
2. Keep changes focused: one fix or feature per PR.
3. Test on Windows with Sonar installed before submitting.
4. Describe what you changed and how you tested it.

## Scope
This tool does one thing: keep Discord audio out of the Sonar - Microphone
device. Changes that keep it small and safe are preferred.
